一毛錢都沒領到，
為什麼還是詐欺既遂？

詐欺取財要詐術、錯誤、交付、取得一環扣一環。錢匯進行為人能控制的帳戶，那一刻就既遂；之後帳戶被凍結、沒領到，不會變回未遂。

一、一環扣一環：詐欺取財的四個步驟

最高法院112年度台上字第4236號說，詐欺取財包含詐術、錯誤、交付、取得等犯罪流程，層層相因、環環相扣；直到行為人或第三人取得財物，才達犯罪終了的階段，在此之前屬於未遂的問題。

① 詐術甲謊稱認識警察
② 錯誤乙信以為真
③ 交付乙匯款10萬元
④ 取得錢進甲能控制的帳戶

用三階來看甲（影片版表格：構成要件客觀在左、主觀在右；第三層稱罪責）：

層次本案結果
一、構成要件・客觀詐術→錯誤→交付→取得；行為結果：取得10萬元✓
一、構成要件・主觀故意（知道自己在騙人）；不法所有意圖（想把10萬元占為己有）✓
二、違法性沒有阻卻違法事由✓
三、罪責沒有問題✓

結論：甲成立詐欺取財既遂（第339條第1項）。甲一個人、用自己的帳戶，沒有冒用公務員名義，也不是三人以上共同犯之，本頁不討論第339條之4加重詐欺。

三階體系因學說不同而有差異；本頁依課程使用的三階論體系參考表。

二、互動：帳戶在什麼時候被凍結？

拖動藍色的「凍結」，放在入帳之前或之後

入帳之後才凍結：既遂（實務見解，112台上4236、108台上56）。

入帳之前已凍結：可能只成立未遂（Claude依112台上4236反推，尚未找到判決）。

四、帳戶被凍結，是既遂還是未遂？

標示說明：最高法院認為＝最高法院自己說明的標準；原審見解・最高法院維持＝最高法院駁回上訴、維持原判決的見解；推論＝本頁依判決反推，尚未找到判決。兩件均於2026-11-07在司法院裁判書系統打開全文、看過歷審。

實務重點

  • 詐欺取財要一環扣一環：詐術 → 錯誤 → 交付 → 取得。到「取得」才既遂，在這之前都是未遂的問題。
  • 錢匯進行為人隨時可以提領的帳戶，行為人就對這筆錢有管領力，錢匯入的那一刻就是既遂。
  • 之後帳戶被警示、凍結或圈存，行為人沒領到錢，也不會變回未遂。
  • 國考：114年移民行政人員考試四等第15題，官方答案(A)既遂（見五、國考）。

最高法院112年度台上字第4236號

加重詐欺等｜112.10.11｜上訴駁回（刑事訴訟法第395條前段）

最高法院認為 帳戶被列為警示帳戶而凍結其內款項前，行為人處於隨時得領取的狀態，對帳戶內款項具有管領力；被害人將財物匯入該帳戶時，即屬詐欺取財既遂，不因其後該帳戶被警示、凍結，未能或不及領取，反而成為未遂犯。

歷審：臺中地院111年度金訴字第2305號 → 臺中高分院112年度金上訴字第1194號 → 本件。案件是詐騙集團，本頁只引用既遂時點的標準。

最高法院108年度台上字第56號

加重詐欺等｜108.01.10｜上訴駁回（刑事訴訟法第395條前段）

原審見解・最高法院維持 款項匯入詐騙集團實際管領支配的人頭帳戶時，即得自主取款，該當詐欺取財既遂；不因款項匯入後隨即遭圈存、無法實際提領而受影響。

歷審：士林地院106年度訴字第122號 → 臺灣高等法院107年度上訴字第577號 → 本件。

推論 延伸想法：如果帳戶「早就」被凍結？

  • 112台上4236的理由是：帳戶「被列為警示帳戶而凍結其內款項前」，行為人隨時可以領，所以有管領力。
  • 反過來想：如果乙匯款的時候，帳戶早就被凍結了，錢一進帳戶就領不出來，甲從頭到尾都沒有控制過這筆錢，「取得」這一環就沒有完成，可能只成立詐欺取財未遂（第339條第3項）。
  • 這是推論。實務上是不是這樣認定，以及屬於哪一種未遂，都還要等判決確認。

五、國考怎麼考

來源：考選部考畢試題查詢平臺。答案依官方「標準答案」PDF的表格逐題核對（2026-11-08）。題目照官方試卷圖片抄錄；解析為本頁整理，考選部只公布答案。

  1. 114年移民行政人員考試四等〈國境執法概要與刑事法概要〉第15題

    甲對乙謊稱認識許多警察可以擺平乙的刑事案件，但需要新臺幣（下同）10萬元之遊說費，乙信以為真將10萬元匯入甲所指定之帳戶，當甲要提領該款項時，該人頭帳戶已被警方凍結，問甲之行為應如何論處？

    1. (A) 甲為詐欺取財罪既遂犯
    2. (B) 甲為詐欺取財罪障礙未遂犯
    3. (C) 甲為詐欺取財罪之不能未遂
    4. (D) 甲無罪
    點我看答案與解析

    答案：(A)

    解析：

    • (A) 錢匯進甲指定的帳戶時，甲已經可以支配這筆錢，詐欺取財既遂；之後要提領才發現凍結，不會變回未遂（最高法院112台上4236）。
    • (B) 障礙未遂是已著手、但因外在障礙沒有既遂；本題錢已入帳，已經既遂。
    • (C) 不能未遂（第26條）是行為不能發生犯罪結果，又沒有危險；本題結果已經發生。
    • (D) 甲施用詐術，乙陷於錯誤而交付，構成要件都符合，不是無罪。

    試題／答案

  2. 113年一般警察人員考試四等行政警察〈刑法概要〉第24題

    甲因犯傷害罪即將入獄執行，乙向甲佯稱可以幫他擺平免入監執行，要求甲給付60萬元報酬。甲信以為真，給付乙60萬元後，乙乃撰寫書狀向地方檢察署書記官請求暫緩甲之執行未果，甲於地方檢察署報到時，方知仍應入監執行。乙之刑事責任為何？

    1. (A) 背信罪
    2. (B) 詐欺罪
    3. (C) 妨礙公務罪
    4. (D) 瀆職罪
    點我看答案與解析

    答案：(B)

    解析：

    • (A) 背信罪（第342條）是為他人處理事務的人違背任務；乙是一開始就謊稱能擺平，用來騙錢，重點在詐術取財。
    • (B) 乙佯稱可以擺平免入監（詐術），甲信以為真而交付60萬元，成立詐欺取財（第339條第1項）。
    • (C) 妨害公務（第135條）要對執行職務的公務員施強暴脅迫；乙只是寫書狀請求暫緩執行。
    • (D) 瀆職罪的行為人要是公務員；題目沒有說乙是公務員。

    試題／答案

  3. 113年原住民族特考四等法警〈刑法與刑事訴訟法概要〉第10題

    甲明知自己無資力仍搭乙所駕之計程車在市區內到處繞行，最後甲要乙停在一家超商前面，佯稱要去超商內領錢支付車資，但是甲下車離去後即不復返。試問依我國實務見解，甲之行為應成立下列何種犯罪？

    1. (A) 詐欺取財罪
    2. (B) 竊盜罪
    3. (C) 侵占罪
    4. (D) 詐欺得利罪
    點我看答案與解析

    答案：(D)

    解析：

    • (A) 詐欺取財騙到的是「物」；甲得到的是搭車服務、免付車資，不是物。
    • (B) 竊盜要竊取他人的動產；甲沒有拿走任何動產。
    • (C) 侵占要先持有他人之物；甲沒有持有乙的東西。
    • (D) 甲用詐術取得搭車、免付車資這種財產上的利益，成立詐欺得利（第339條第2項）。

    試題／答案

  4. 113年司法人員特考四等法警等〈刑法概要〉第48題

    下列何者不成立詐欺罪？

    1. (A) 自始無付錢意思而在餐館白吃白喝
    2. (B) 冒稱自己為小開而向他人求婚
    3. (C) 自始無付錢意思而搭計程車
    4. (D) 車商不告知買主所購買之車輛曾遭重大事故
    點我看答案與解析

    答案：(B)

    解析：

    • (A) 自始不打算付錢卻點餐，點餐本身就表示會付錢，店家因此送上餐點，成立詐欺罪。
    • (B) 詐欺罪是財產犯罪，要使人交付財物或得到財產上的利益；單純冒稱小開求婚，沒有取得財物或利益，不成立詐欺罪。
    • (C) 自始不打算付錢而搭車，取得搭車的財產上利益，成立詐欺得利（同上一題）。
    • (D) 依本題官方答案，屬於成立詐欺罪的情形：車商隱瞞重大事故，買主誤以為車況正常而付款。

    試題／答案

申論題（列出處，可以自己練習）

  • 113年高考三級法制〈刑法〉第三題：詐騙集團首腦訓練話術、冒充檢察官、刊登投資廣告，論處與沒收犯罪所得。
  • 114年司法特考三等觀護人〈刑法〉第二題：境外語音假冒檢察官、販賣個資、加密貨幣洗錢。
  • 114年司法特考四等法院書記官〈刑法概要〉第二題：車手轉投另一集團，花用詐欺所得未繳回。
  • 114年高考三級司法行政〈刑法〉第二題：借錢給詐騙組織，對方未使用即返還，借錢的人是否構成犯罪。

申論題多涉及第339條之4加重詐欺、共犯與沒收，超出本頁範圍，只列出處。

六、六題練習：錢進帳戶那一刻

每題選一項，再選「有把握」或「用猜的」，就會看到理由。六題做完，下方會出現你的學習診斷。

四個步驟：詐術 → 錯誤 → 交付 → 取得，取得才既遂。

匯款：錢進行為人能控制的帳戶，就是取得；事後凍結不影響既遂。

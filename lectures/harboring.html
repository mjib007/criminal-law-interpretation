叫朋友頂罪、丟證據，
自己為什麼不犯這兩罪？

替犯人頂罪是頂替罪（第164條第2項）；丟掉別人案件的證據是湮滅證據罪（第165條）。但出主意的犯人自己，這兩罪都不罰——最高法院說，那只是自己庇護的延伸。

乙、丙都犯罪了，出主意的甲，反而不犯這兩罪？影片先看條文，再看最高法院怎麼說。

一、三個人，三個結果

人做了什麼結果
乙向警察說「是我開的」，替甲頂罪第164條第2項 頂替罪
丙把甲車上的行車紀錄器記憶卡丟掉第165條 湮滅證據罪（對丙來說，是「他人」刑事被告案件的證據）
甲叫乙頂替、叫丙丟證據不成立這兩罪的教唆犯（酒駕本身仍另成立第185條之3公共危險罪）

為什麼甲不罰？

  • 自己躲、自己丟本來就不罰：第164條處罰藏匿「犯人」，第165條處罰湮滅「他人」刑事被告案件的證據。犯人自己躲、自己丟自己案件的證據，都不符合條文。
  • 叫別人做，也不罰：最高法院112年度台非字第12號說，犯人教唆他人藏匿、隱避或頂替自己，是「自己庇護之延伸」，顯無期待可能性；自己做（正犯）都不罰，舉重以明輕，叫別人做（教唆）也不罰。
  • 湮滅證據也一樣：最高法院沒有找到直接判決，但114年移民特考第16題官方答案是「甲不成立湮滅證據罪之教唆犯，丙成立直接正犯」；最高法院94年度台上字第5721號也說，第165條以所湮滅者非其本人犯罪之證據為要件。

兩個小提醒：第165條只限刑事案件的證據，隱匿民事訴訟的證據不成立本罪（114年法警第32題）。丙如果在甲的案件裁判確定前自白，減輕或免除其刑（第166條，和第13集偽證罪的第172條同一個設計）。

二、互動：換一個人幫忙，結果一樣嗎？

選一種情況

第167條的親屬：配偶、五親等內之血親、三親等內之姻親，而且要「圖利犯人」。女朋友、同居人不在範圍（114年書記官第14題、113年書記官第15題）。

朋友頂罪：第164條第2項頂替罪。

朋友丟證據：第165條湮滅證據罪。

甲自己躲：不成罪。

哥哥藏匿：成立藏匿人犯罪，減輕或免除其刑（第167條）。

女朋友藏匿：成立藏匿人犯罪，不能減免。

民事證據：不成立第165條。

四、實務：自己庇護的延伸

標示說明：最高法院認為＝最高法院自己說明的標準。2026-11-10在司法院裁判書系統打開全文、看過歷審。

最高法院112年度台非字第12號

教唆頂替｜113.02.29｜非常上訴，原判決撤銷，改判無罪

最高法院認為 犯人自行藏匿、隱避，本即不該當第164條第1項；亦無從頂替自己。犯人教唆他人藏匿、隱避或頂替自己，俱屬自己庇護之延伸，顯無期待可能性。正犯行為既不處罰，舉重以明輕，參與他人藏匿、隱避或頂替之共犯行為，自亦無處罰之理；犯人教唆他人頂替自己，當然亦在不罰之列。

案情：被告開車撞傷人，因另案通緝，叫朋友到場向警察說是朋友開的。一審（宜蘭地院簡易判決）判教唆頂替有期徒刑3月確定，檢察總長提起非常上訴。先前最高法院裁判有肯定、否定兩說，本件經徵詢程序，各刑事庭都採否定說。

最高法院94年度台上字第5721號

貪污等｜94.10.14｜撤銷發回

最高法院認為 第165條所謂湮滅、隱匿關係他人刑事被告案件之證據，必以所湮滅、隱匿者非其本人犯罪之證據為要件，否則縱與其他共同被告有關，亦難論以湮滅、隱匿刑事證據罪名。

案情：鄉公所人員浮報擋土牆工程款，事後叫人挖倒擋土牆。最高法院質疑原審把這件事論為湮滅證據罪，撤銷發回。

舊判例已停止適用

最高法院24年上字第4974號（教唆他人頂替自己不罰）、25年上字第4435號（第165條限於非本人犯罪之證據）兩則舊判例，都因無裁判全文，依法院組織法第57條之1第1項於108年7月4日停止適用。112台非12正是因為舊判例停止適用、見解分歧，才經徵詢程序重新統一。

五、國考怎麼考

來源：考選部考畢試題查詢平臺。試題、標準答案與更正清冊都轉成圖片逐格核對（2026-11-10）；題目照官方試卷圖片抄錄。解析為本頁整理，考選部只公布答案。

  1. 114年司法人員特考四等法警（代號4202）第4題

    甲為A上市公司執行長，某日酒駕肇事，乃與坐在副手座的乙交換，並提供新臺幣300萬元安家費，要乙承認自己為駕駛人。依實務見解，下列何者正確？

    1. (A) 甲成立刑法第164條第2項意圖隱避犯人頂替罪之教唆犯
    2. (B) 乙成立刑法第164條第2項意圖隱避犯人頂替罪之幫助犯
    3. (C) 甲成立刑法第164條第2項的意圖隱避犯人頂替罪
    4. (D) 乙成立刑法第164條第2項的意圖隱避犯人頂替罪
    點我看答案與解析

    答案：(D)

    解析：

    • (A) 犯人教唆他人頂替自己，是自己庇護的延伸，不罰（112台非12）。
    • (B) 乙自己出面冒充駕駛人，是頂替罪的正犯，不是幫助犯。
    • (C) 甲是犯人本人，無從頂替自己。
    • (D) 正確（本題答案）：乙意圖使犯人隱避而頂替，成立第164條第2項。

    試題／答案

  2. 113年司法官考試（第一試）及律師考試（第一試）〈綜合法學(一)〉第18題

    犯人甲為逃避刑罰，躲藏數日後，去找其兄乙哭訴；乙自幼愛護甲，知悉情形後，安排甲躲藏於住家密室。下列敘述何者正確？

    1. (A) 甲為了逃避刑罰而自行藏匿，屬於自我庇護行為，不成立藏匿人犯罪；乙為甲的近親，藏匿甲為人之常情，法律不強人所難，故不成立犯罪
    2. (B) 甲為了逃避刑罰而自行藏匿，雖屬於自我庇護行為，但仍成立藏匿人犯罪；乙為甲的近親，藏匿甲為人之常情，法律不強人所難，故不成立犯罪
    3. (C) 甲為了逃避刑罰而自行藏匿，屬於自我庇護行為，不成立藏匿人犯罪；乙為甲的近親，藏匿甲為人之常情，雖成立藏匿人犯罪，但依法減免處罰
    4. (D) 甲為了逃避刑罰而自行藏匿，雖屬自我庇護行為，但仍成立藏匿人犯罪；乙為甲的近親，藏匿甲為人之常情，雖成立藏匿人犯罪，但依法減免處罰
    點我看答案與解析

    答案：(C)

    解析：

    • (A) 乙仍成立犯罪，第167條只是減輕或免除其刑。
    • (B) 甲自行藏匿不成罪；乙也不是不成罪。
    • (C) 正確（本題答案）：甲自我庇護不成罪；哥哥是二親等血親，成立藏匿人犯罪，依第167條減免。
    • (D) 甲自行藏匿不成立藏匿人犯罪。

    試題／答案

  3. 114年移民行政人員特考（代號901）第16題

    甲將乙殺害後，委由丙將殺害乙之兇刀與血衣加以掩埋，關於湮滅證據之行為，甲、丙應如何論處？

    1. (A) 甲成立「湮滅證據罪」之教唆犯，丙成立「湮滅證據罪」之直接正犯
    2. (B) 甲不成立「湮滅證據罪」之教唆犯，丙成立「湮滅證據罪」之直接正犯
    3. (C) 甲與丙成立「湮滅證據罪」之共同正犯
    4. (D) 甲成立「湮滅證據罪」之直接正犯，丙成立「湮滅證據罪」之幫助犯
    點我看答案與解析

    答案：(B)

    解析：

    • (A) 兇刀、血衣是甲自己案件的證據，甲叫別人湮滅，依官方答案不成立教唆犯。
    • (B) 正確（本題答案）：丙湮滅的是他人（甲）刑事案件的證據，成立直接正犯；甲不成立教唆犯。
    • (C) 第165條限「他人」案件的證據，甲不能是本罪正犯。
    • (D) 同上，甲不是本罪正犯；丙自己掩埋，是正犯。

    試題／答案

  4. 114年司法人員特考四等法警（代號4202）第32題

    甲知悉乙與他人之債務糾紛，尚在民事法院訴訟中，乃隱匿該案之證據。關於甲之行為，下列何者正確？

    1. (A) 不成立犯罪
    2. (B) 偽證罪
    3. (C) 湮滅證據罪
    4. (D) 妨害公務罪
    點我看答案與解析

    答案：(A)

    解析：

    • (A) 正確（本題答案）：第165條限「刑事被告案件」的證據，民事訴訟的證據不在內。
    • (B) 甲沒有以證人身分具結作虛偽陳述。
    • (C) 湮滅證據罪限刑事案件。
    • (D) 甲沒有對公務員施強暴脅迫。

  5. 113年司法人員特考四等法院書記官〈刑法概要〉第15題

    甲搶劫銀樓後，商請其女友乙協助，使其躲藏於乙之租屋處，兩人共同將得手金飾燒熔成金塊。有關乙之刑事責任，下列敘述何者正確？

    1. (A) 成立藏匿人犯罪
    2. (B) 成立準強盜罪
    3. (C) 不成立犯罪
    4. (D) 成立湮滅刑事證據罪之幫助犯
    點我看答案與解析

    答案：(A)

    解析：

    • (A) 正確（本題答案）：乙讓犯人甲躲在租屋處，成立藏匿人犯罪；女朋友不是第167條的親屬。
    • (B) 乙沒有竊盜、搶奪後當場施強暴脅迫。
    • (C) 依官方答案，乙成立藏匿人犯罪。
    • (D) 兩人「共同」燒熔金飾，不是單純幫助；本題官方答案為(A)。

  6. 114年司法人員特考四等法院書記官〈刑法概要〉第14題

    甲持刀傷害A致死，聯絡同居人乙騎車到現場，知情的乙載甲前往乙租屋處藏匿。警方隨即展開調查，甲藏匿一個月後，仍遭警察查獲。有關甲、乙之刑責，下列敘述何者正確？

    1. (A) 乙成立傷害致死罪之幫助犯
    2. (B) 乙僅為同居人，其藏匿人犯行為不得減免其刑
    3. (C) 甲成立藏匿人犯罪之教唆犯
    4. (D) 藏匿人犯罪之所謂「犯人」，以起訴後之人為限，乙不成立藏匿人犯罪
    點我看答案與解析

    答案：(B)

    解析：

    • (A) 乙是在甲傷害A之後才來，沒有幫助傷害行為。
    • (B) 正確（本題答案）：同居人不是配偶或第167條的親屬，不得減免。
    • (C) 犯人教唆他人藏匿自己，不罰（112台非12）。
    • (D) 依官方答案，此敘述錯誤；「犯人」不以起訴後為限。

六、六題練習：成不成罪？

每題選一項，再選「有把握」或「用猜的」，就會看到理由。六題做完，下方會出現你的學習診斷。

幫忙的人：藏匿、使之隱避、頂替，第164條；湮滅他人刑事案件證據，第165條。

犯人自己：自己躲、自己丟，或叫別人幫自己，都不成立這兩罪（112台非12）。

親屬：配偶、五親等內血親、三親等內姻親，減輕或免除其刑（第167條）；女朋友、同居人不算。

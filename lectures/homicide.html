一、殺人和傷害，差在殺意

殺人罪（第271條）普通傷害罪（第277條第1項）
主觀殺人故意（殺意）傷害故意
法定刑死刑、無期徒刑或10年以上有期徒刑5年以下有期徒刑、拘役或50萬元以下罰金
未遂罰（第2項）不罰
預備罰，2年以下（第3項）不罰

所以「刺了一刀、人沒死」：有殺意，是殺人未遂（10年以上打底，再依未遂減輕）；沒有殺意，是傷害（5年以下）。最高法院說：殺人與傷害之區別，應以行為人於加害時，有無殺意為斷（109年度台上字第5623號）。

法院從哪些事實推殺意？

事實甲（A案）丙（B案）
兇器事先準備長刀隨手抓水果刀
攻擊部位胸口刺一刀
力道、次數連刺好幾刀一刀
傷勢送醫救回送醫救回
動機舊仇當場吵架
事後舉動乙倒地還繼續刺同事一喊就丟刀離開

這不是加分公式。109台上5623要法院依行為當時一切情況，審酌受傷部位、傷勢、兇器、下手情形（力道、次數）、傷痕多寡，並斟酌客觀環境綜合判斷。

甲的三階

層次本案結果
一、構成要件・客觀持刀連刺乙胸口，已著手殺人；乙沒有死亡未遂
一、構成要件・主觀殺人故意（從兇器、部位、次數、倒地仍刺推得）✓
二、違法性沒有阻卻違法事由✓
三、罪責沒有問題✓

結論：甲成立殺人未遂罪（第271條第2項、第1項）。丙沒有殺意、有傷害故意，成立傷害罪（第277條第1項）。

二、互動：殺意推理器

先選甲或丙，再自己改改看每一項事實

甲、乙、丙、丁都是教學假設。這裡只把「哪些事實指向殺意」排在一起看，不是加分公式；實際案件要依行為當時一切情況綜合判斷（109台上5623）。

甲：事先準備長刀、連刺胸口、倒地還刺、有舊仇，多項事實指向殺意，論殺人未遂。

丙：隨手拿刀、刺一刀、有人喊就停、當場口角，論傷害。

只改部位不夠：砍四肢也可能有殺意（113台上1799）；傷口深達胸腔也可能只是傷害（108台上4326）。

四、實務見解

標示說明：最高法院認為＝最高法院自己說明的標準；原審見解・最高法院維持＝最高法院駁回上訴，維持原判決的認定。三件都在2026-11-09於司法院裁判書系統打開全文、看過歷審，都是依刑事訴訟法第395條前段從程序上駁回上訴。

最高法院109年度台上字第5623號

殺人未遂｜110.08.12｜上訴駁回

最高法院認為 殺人與傷害之區別，應以行為人於加害時，有無殺意為斷。法院應依行為當時所存在之一切情況加以審酌，除受傷部位是否為致命部位、傷勢輕重、兇器、下手情形（包含力道、次數）、傷痕多寡外，並斟酌當時客觀環境及其他具體相關情形，綜合判斷。

原審見解・最高法院維持 持蝴蝶刀朝胸、腹部攻擊，告訴人倒地後仍繼續揮刺，多處傷勢集中於胸、腹及背部，認有殺人故意。

歷審：臺南地院一審 → 臺南高分院改判殺人未遂 → 最高法院程序駁回。

最高法院113年度台上字第1799號

殺人未遂｜113.07.11｜上訴駁回

原審見解・最高法院維持 傷痕多寡、是否致命部位、傷勢、下手情形、兇器等，雖不能執為區別之絕對標準，仍可綜合觀察動機、衝突起因、力道、攻擊部位、次數、兇器與致傷結果。備妥約50公分西瓜刀尋仇，朝頭部及四肢猛砍；被告辯稱「傷勢集中於四肢，並非致命部位」不採，認有殺人之不確定故意。

歷審：宜蘭地院一審 → 臺灣高等法院 → 最高法院程序駁回。砍在手腳，也可能有殺意。

最高法院108年度台上字第4326號

傷害｜108.12.12｜上訴駁回

原審見解・最高法院維持 殺人與傷害之區別以有無殺意為斷，二罪皆發生傷害之結果，只其主觀犯意不同而已。口角後隨手持水果刀戳刺，傷口深達10公分以上，但雙方無深仇大恨、傷口不集中、經勸阻即離開未再攻擊，仍論傷害罪；檢察官主張殺人未遂的上訴被駁回。

歷審：桃園地院一審 → 臺灣高等法院撤銷改判仍論傷害 → 最高法院程序駁回。傷口很深，也可能只是傷害。

五、國考怎麼考

來源：考選部考畢試題查詢平臺。試題、標準答案（與更正清冊，有者）都轉成圖片逐格核對（2026-11-09）；題目照官方試卷圖片抄錄。解析為本頁整理，考選部只公布答案。

  1. 113年司法官考試（第一試）及律師考試（第一試）〈綜合法學(一)〉第27題

    關於傷害罪，依實務見解，下列敘述何者正確？

    1. (A) 刑法第278條「重傷」之標準，乃是以傷害初始之檢驗狀況為準
    2. (B) 若聚眾鬥毆時，在場助勢之人與實行傷害行為之行為人間有犯意聯絡和行為分擔時，才能成立聚眾鬥毆罪
    3. (C) 刑法第286條之凌虐行為不以長期性、持續性、多次性為必要
    4. (D) 殺人罪與傷害致死罪之間，以受傷處是否為致命部位為其區別基準
    點我看答案與解析

    答案：(C)

    解析：

    • (A) 依本題官方答案，此項不正確。重傷依第10條第4項，看傷害是否達到毀敗或嚴重減損機能，或「重大不治或難治」，本頁不展開實務怎麼認定時點。
    • (B) 依本題官方答案，此項不正確；在場助勢之人與實行傷害者若有犯意聯絡與行為分擔，可能另論傷害的共同正犯，本頁不展開。
    • (C) 正確。第10條第7項：稱凌虐者，謂以強暴、脅迫或其他違反人道之方法，對他人施以凌辱虐待行為；依本題官方答案，不以長期性、持續性、多次性為必要。
    • (D) 錯誤。殺人與傷害（致死）的區別在行為時有無殺意，致命部位只是判斷因素之一（109台上5623、113台上1799）。影片S5點出的就是這個選項。

    試題／答案

  2. 114年司法人員特考四等法警、執達員、監所管理員〈刑法概要〉第14題

    甲懷疑其妻乙外遇，以殺人故意砍殺乙一刀，甲見乙倒地呻吟心生不忍，電召救護車將乙送醫，乙因而獲救，下列敘述何者正確？

    1. (A) 甲成立殺人罪之障礙未遂
    2. (B) 甲成立殺人罪之中止未遂
    3. (C) 甲成立殺人罪之不能未遂
    4. (D) 甲成立殺人罪之失敗未遂
    點我看答案與解析

    答案：(B)

    解析：

    • (A) 障礙未遂是因外在障礙而沒有既遂；本題是甲自己叫救護車。
    • (B) 正確。甲已著手殺人，因己意防止結果發生，乙獲救，依第27條第1項是中止未遂，減輕或免除其刑。
    • (C) 不能未遂（第26條）是行為不能發生結果又無危險；砍人一刀不是這種情形。
    • (D) 依本題官方答案不選。

    試題／答案

  3. 114年司法人員特考四等法警、執達員、監所管理員〈刑法概要〉第11題

    關於構成要件錯誤，下列敘述何者正確？

    1. (A) 甲欲射殺乙，因手抖誤擊旁邊的丙，此為客體錯誤
    2. (B) 甲欲射殺乙，卻誤丙為乙而射殺丙，甲成立刑法第271條第1項殺人既遂罪
    3. (C) 甲欲射殺乙，卻因手抖擊中旁邊的A犬，甲成立刑法第271條第1項殺人既遂罪
    4. (D) 甲欲射殺A犬，卻因手抖而誤擊旁邊的乙，致乙死亡，甲成立刑法第271條第1項殺人既遂罪
    點我看答案與解析

    答案：(B)

    解析：

    • (A) 手抖打到旁邊的人，是打擊錯誤，不是客體錯誤。
    • (B) 正確。誤認對象（客體錯誤），乙、丙都是「人」，構成要件上等價，仍成立殺人既遂。
    • (C) 打中的是狗，人沒死，不會是殺人既遂。
    • (D) 甲沒有殺人故意，乙死亡是過失造成，不會成立殺人既遂。

  4. 113年公務人員高等考試三級考試司法行政〈刑法〉第4題

    下列關於殺人罪之說明，何者錯誤？

    1. (A) 義憤殺人罪屬減輕構成要件
    2. (B) 受囑託殺人罪屬減輕構成要件
    3. (C) 義憤殺人罪限於當場激於義憤
    4. (D) 生母殺嬰罪屬加重構成要件
    點我看答案與解析

    答案：(D)

    解析：

    • (A) 正確。第273條處7年以下，比普通殺人輕。
    • (B) 正確。第275條第1項處1年以上7年以下。
    • (C) 正確。第273條明文「當場激於義憤」。
    • (D) 錯誤，所以選它。第274條生母殺嬰處6月以上5年以下，是減輕類型。

    試題／答案

  5. 113年公務人員高等考試三級考試司法行政〈刑法〉第3題

    下列關於傷害罪之說明，何者錯誤？

    1. (A) 我國刑法對於何謂重傷，採取立法定義之方式予以規範
    2. (B) 加工自傷罪並不包括輕傷之情形
    3. (C) 我國刑法不處罰過失致輕傷之行為
    4. (D) 傷害罪之保護對象不包括胎兒
    點我看答案與解析

    答案：(C)

    解析：

    • (A) 正確。第10條第4項定義重傷。
    • (B) 正確。第282條只規定致死、致重傷，不包括輕傷。
    • (C) 錯誤，所以選它。第284條處罰過失傷害人（1年以下），致重傷另有較重刑度。
    • (D) 依本題官方答案正確。

六、六題練習：殺人未遂還是傷害？

每題選一項，再選「有把握」或「用猜的」，就會看到理由。六題做完，下方會出現你的學習診斷。

分界：殺人與傷害，看行為當時有沒有殺意。

怎麼判斷：兇器、部位、力道次數、傷勢、動機、事後舉動，綜合判斷；不能只看致命部位。

刑度：殺人10年以上、罰未遂與預備；普通傷害5年以下、不罰未遂。

妨害公務罪保護的是公務能順利執行，不是警察個人。要過兩道關卡：先問警察是不是依法執行職務，再看有沒有施強暴脅迫；而且不必真的讓公務停下來。

一、兩道關卡

關卡意思本案
第一關：依法執行職務依據法令，在職權範圍內執行應為或得為的事項（115台上2333）。超越職務範圍，就不是依法執行職務，縱令加以妨阻，也沒有妨害公務可言（30上955）。違規擺攤（違反行政法上義務）→ 拒絕表明身分、勸導無效 → 確實無法辨認身分且情況急迫 → 依行政罰法第34條第1項第4款帶回查證 ✓
第二關：強暴脅迫強暴是施用體力，形成對他人的強制或逼迫作用；包括迫使他人不做本來要做的事。不以真的妨害成功為必要（115台上2333）。甩手想讓員警不能帶人，雖然沒有成功，仍是強暴 ✓
層次本案結果
一、構成要件・客觀員警依法執行職務時，甲甩手施強暴✓
一、構成要件・主觀知道對方是執行職務的員警，仍甩手（妨害公務的故意）✓
二、違法性沒有阻卻違法事由（員警依法執行，甲不能主張正當防衛）✓
三、罪責沒有問題✓

結論：甲成立妨害公務罪（第135條第1項）；員警擦傷，另成立傷害罪（第277條第1項）。一個行為觸犯兩罪，想像競合從一重處斷。115台上2333 的二審就是從一重論傷害罪（傷害罪刑度五年以下，比妨害公務的三年以下重），判拘役30日。

二、互動：四種情境，算不算妨害公務？

選一種情境

甲是教學假設；第一種改寫自115台上2333，第三種改寫自國考題。

拒查身分甩開員警：成立妨害公務罪（115台上2333）。

員警沒有依據就搜包：不是依法執行職務，不成立本罪（30上955）。

把便衣刑警當成仇人：不知道對方是公務員，欠缺故意，不成立本罪（114法警第28題）。

當場辱罵員警：不是強暴脅迫；第140條另有要件（113憲判5）。

三、第135條、第140條逐句讀

第135條第1項是本集主角；第3項開車或帶兇器加重，第4項致死、致重傷再加重。第140條處罰當場侮辱公務員，但已被憲法法庭限縮。

四、實務見解

標示說明：最高法院認為＝最高法院自己說明的標準；原審見解・最高法院維持＝最高法院駁回上訴，維持原判決的認定。2026-11-09在司法院裁判書系統、法令判解系統、憲法法庭網站讀過全文。

最高法院115年度台上字第2333號

傷害（妨害公務）｜115.06.25｜上訴駁回（刑事訴訟法第395條前段）

最高法院認為 第135條第1項所謂「依法執行職務」，係指依據法令於職權範圍內執行其應為或得為之事項。第135條所定之強暴，指施用體力，形成對於他人之強制或逼迫作用；不以使人為其所不願為之事為限，尚包含迫使他人不為其本欲為之事或忍受行為人的行為。甩手雖終未達成妨害公務之目的，仍符合「強暴」。

原審見解・最高法院維持 違規擺攤、拒絕表明身分且勸導無效，確有無法辨認身分且情況急迫之情形；員警告知後強制帶回查證，符合行政罰法第34條第1項第4款，縱誤引警察職權行使法，也不影響執行職務的合法性。

歷審：新北地院114易938判無罪 → 臺灣高等法院114上易2271撤銷改判，從一重論傷害罪，拘役30日 → 最高法院程序駁回。

最高法院30年上字第955號

原為判例；依法院組織法第57條之1第2項，效力與一般最高法院裁判相同

最高法院認為 妨害公務罪以公務員依法執行職務時加以妨害為要件，若超越職務範圍以外之行為，即不得謂為依法執行職務，縱令對之有所妨阻，要無妨害公務之可言。

案情：分局長率員查緝私硝，查獲後因爭執竟下令毆打，已逸出執行職務範圍，被告反擊不成立妨害公務。113台上3393仍引用這個見解。影片的「沒有依據就搜包」是教學假設，不是本件事實。

憲法法庭113年憲判字第5號

侮辱公務員罪及侮辱職務罪案｜113.05.24

主文一：第140條侮辱公務員罪部分，應限於當場侮辱、基於妨害公務之主觀目的，且足以影響公務員執行公務，於此範圍內合憲。

主文二：侮辱職務罪部分（「對於其依法執行之職務公然侮辱」）違憲，自113.05.24起失效。全國法規資料庫的條文文字仍完整顯示，讀條文時要記得這一段已經失效。

最高法院115年度台上字第612號

妨害公務（第140條）｜115.03.04｜撤銷發回（未確定）

最高法院認為 第140條保護公務執行之國家法益，與第309條公然侮辱罪保護個人名譽不同。單純口頭抱怨或一時情緒性辱罵，通常不致妨害公務的後續執行；公務員能以合法手段即時制止時，未先警告或制止，尚不得逕認成立。觸及身體的侮辱（潑穢物、吐痰）或多數人集體持續辱罵，則毋須先行制止。

案情：受刑人在視訊詢問中辱罵檢事官，詢問約12分鐘就在預期時間內結束。原審改判有罪，最高法院以理由不備發回。

五、國考怎麼考

來源：考選部考畢試題查詢平臺。試題與標準答案都轉成圖片逐格核對（2026-11-09）；題目照官方試卷圖片抄錄。解析為本頁整理，考選部只公布答案。

  1. 113年司法官考試（第一試）及律師考試（第一試）〈綜合法學(一)〉第17題

    關於侵害國家權力運作法益的犯罪敘述，依實務見解，下列何者錯誤？

    1. (A) 刑法第161條第2項以強暴脅迫脫逃之罪為第135條妨害公務罪之特別規定，於該當二者之構成要件時，應直接適用前者
    2. (B) 妨害公務罪，以公務員依法執行職務時加以妨害為要件，若超越職務範圍以外之行為，即不得謂為依法執行職務
    3. (C) 刑法第143條所謂有投票權之人，包括收賄時尚不具投票資格，但收賄後獲得投票權而得履行期約事項之人
    4. (D) 刑法第131條圖利罪所謂直接或間接圖自己或其他私人不法利益，僅指一切有形增加之財產數額，不包括法律上應減少而未減少之利益
    點我看答案與解析

    答案：(D)

    解析：

    • (A) 依本題官方答案為正確敘述：以強暴脅迫脫逃，同時該當第135條時，適用第161條第2項。
    • (B) 正確敘述，就是本集S4的重點；同旨見最高法院30年上字第955號。
    • (C) 依本題官方答案為正確敘述。
    • (D) 錯誤：圖利罪的「利益」也包括應減少而未減少的消極利益，不限於有形增加的財產。

    試題／答案

  2. 113年司法官考試（第一試）及律師考試（第一試）〈綜合法學(一)〉第19題

    甲、乙、丙三人因夜市擺攤糾紛，毆打隔壁攤位的丁，使丁受到輕傷，但並未波及其他攤位或周邊居民，正在巡邏的警察戊剛好在夜市裡購買晚餐，聽到有吵鬧聲及警網通報前往處理時，甲、乙、丙因害怕被逮捕，一起將圓凳砸向戊之後，拔腿就跑。依實務見解，甲、乙、丙可能構成下列何罪？

    1. (A) 刑法第135條第1項妨害公務罪
    2. (B) 刑法第150條第1項妨害秩序罪
    3. (C) 刑法第161條第1項脫逃罪
    4. (D) 刑法第283條聚眾鬥毆罪
    點我看答案與解析

    答案：(A)

    解析：

    • (A) 戊接獲通報前往處理，是依法執行職務；三人把圓凳砸向戊，是施強暴，成立妨害公務罪。
    • (B) 依本題官方答案不論；題目特別說明沒有波及其他攤位或周邊居民。
    • (C) 脫逃罪要「依法逮捕、拘禁之人」脫逃；三人還沒被逮捕。
    • (D) 聚眾鬥毆罪以致人於死或重傷為要件；丁只受輕傷。

    試題／答案

  3. 114年司法官考試（第一試）及律師考試（第一試）〈綜合法學(一)〉第16題

    關於公務員所為的犯罪或對公務員所為的犯罪敘述，下列何者錯誤？

    1. (A) 公務員同時該當刑法第122條違背職務受賄罪與第131條圖利罪之構成要件時，應優先適用前者
    2. (B) 公務員違犯刑法第213條明知不實而登載於職務上所掌公文書罪時，另得依刑法第134條加重其刑
    3. (C) 刑法第135條第1項妨害公務罪，倘非於公務員依法執行職務時而對其施強暴脅迫者，即無妨害公務可言
    4. (D) 刑法第138條所謂公務員職務上掌管之物品，以該物品由公務員本於職務上之關係所掌管者為已足，與物品之所有權無涉
    點我看答案與解析

    答案：(B)

    解析：

    • (A) 依本題官方答案為正確敘述。
    • (B) 錯誤：第134條但書規定，因公務有關之身分已特別規定其刑者，不再加重；第213條本來就是公務員才會犯的罪。
    • (C) 正確敘述：不是依法執行職務，就沒有妨害公務可言。
    • (D) 依本題官方答案為正確敘述。

    試題／答案

  4. 114年司法人員特考四等法警、執達員、監所管理員〈刑法概要〉第28題

    有關妨害公務罪的敘述，下列何者錯誤？

    1. (A) 本罪性質為結果犯，須使公務員執行職務確有遭到妨害之結果
    2. (B) 以強暴、脅迫手段對公務員非法職務行為加以反抗，不成立本罪
    3. (C) 駕駛動力交通工具對公務員施強暴脅迫者，構成加重妨害公務罪
    4. (D) 通緝犯將便衣刑警誤認為尋仇之人，而將其推倒在地反抗逮捕，不成立本罪
    點我看答案與解析

    答案：(A)

    解析：

    • (A) 錯誤：不必真的讓公務停下來。115台上2333的甩手「雖終未達成妨害公務之目的」，仍屬強暴。
    • (B) 正確：非依法執行職務不受第135條保護。
    • (C) 正確：第135條第3項第1款。
    • (D) 正確：通緝犯不知道對方是公務員，欠缺妨害公務的故意。

六、六題練習：算不算妨害公務？

每題選一項，再選「有把握」或「用猜的」，就會看到理由。六題做完，下方會出現你的學習診斷。

第一關：依法執行職務；超越職務範圍就不受保護。

第二關：施強暴脅迫；不必真的妨害成功。

加重：開車、帶兇器（第135條第3項）。

罵人：不是強暴；第140條限縮適用。

01｜準備工具：安裝 Python 與 Jupyter

這一步在做什麼：在自己的電腦上準備好寫程式需要的工具。請在課前完成。

為什麼要做這一步？ 程式要有 Python 才能執行。我們另外建一個叫 law-vibe 的「課程專用工具箱」（專業名詞叫「環境」）：不同課程或專案需要的工具版本可能不同，分開放才不會互相干擾；全班版本一樣，看到的畫面也一樣，卡住時比較好互相幫忙。

步驟 1｜安裝 Anaconda（已經裝過的同學看第 3 點）

  1. 到 Anaconda 官方下載 下載 Windows 版安裝程式。
  2. 安裝時選 Just Me（只給自己用）；「加入 PATH」的選項維持預設，不用勾。
  3. 裝好後，從開始選單打開 Anaconda Prompt，輸入 conda --version 按 Enter。看到版本號碼就代表可以用了。已經有 Anaconda 或 Miniconda 的同學，看得到版本號就直接沿用，不必重裝。

步驟 2｜建立課程工具箱：在 Anaconda Prompt 一次貼一行，每行按 Enter。

conda create -n law-vibe python=3.12 notebook ipykernel
conda activate law-vibe
指令 白話意思
conda create -n law-vibe python=3.12 notebook ipykernel 建立名叫 law-vibe 的工具箱，裝進 Python 3.12 和 Jupyter
conda activate law-vibe 打開這個工具箱，之後的指令都用裡面的工具

第一行執行時會問 Proceed ([y]/n)?（要不要繼續），看完畫面後輸入 y 按 Enter；若出現服務條款提示，依學校及個人適用條件處理。完成後每行開頭會出現 **(law-vibe)**，表示你已經在工具箱裡。本課統一用 Python 3.12，是為了全班一致，不是因為它最新。

步驟 3｜建立作業資料夾，打開 Jupyter：繼續在同一個視窗，一次貼一行。

if not exist "%USERPROFILE%\law_vibe" mkdir "%USERPROFILE%\law_vibe"
cd /d "%USERPROFILE%\law_vibe"
python -m notebook
指令 白話意思
if not exist … mkdir … 如果還沒有 law_vibe 資料夾，就建一個。本課所有檔案都放這裡
cd /d "%USERPROFILE%\law_vibe" 走進這個資料夾。%USERPROFILE% 會自動換成你的使用者資料夾，例如 C:\Users\Amy
python -m notebook 啟動 Jupyter，瀏覽器會自動打開

做對了會看到：瀏覽器打開 Jupyter 頁面，列出 law_vibe 資料夾的內容（剛建好可能是空的）。如果瀏覽器沒有自動打開，把 Prompt 裡顯示的 http://localhost:8888/... 整串網址貼到瀏覽器。

注意

  • 這個 Prompt 視窗不要關，關掉 Jupyter 就停了。
  • 網址裡 token= 後面那一長串是登入密碼，不要貼到群組或公開的地方。
  • 這些指令只能貼在 Anaconda Prompt。貼到 PowerShell、Notebook 或出現 >>> 的畫面都會出錯。Mac 的指令不同，Mac 同學請另外詢問老師。

03｜先定答案，再請 AI 幫忙

這一步在做什麼：先自己算出正確答案，再把需求寫清楚交給 AI。

為什麼要做這一步？ AI 寫程式很快，但它說「完成了」不代表是對的。請助理寫書狀前，你心裡要先有結論和要件，才能檢查助理寫得對不對。寫程式也一樣：先有已知答案，才能驗收 AI 的成果。

先手算：會議 45 分鐘＋整理資料 30 分鐘＝75 分鐘，也就是 1 小時 15 分鐘。這就是等一下拿來對照的標準答案。

再寫需求：把下面整段提示詞貼到 AI 對話視窗。這是給 AI 看的需求，不要貼進 Code 格。

我要做一個給法律系學生練習的「案件工時紀錄器」。
請先用白話重述需求，再提供完整的 worklog.py 程式。
需求：
1. 使用虛構活動：會議 45 分鐘、整理資料 30 分鐘。
2. 印出每項活動，最後印出總分鐘與幾小時幾分鐘。
3. 分鐘只能是非負整數；文字、小數、負數與布林值都要拒絕，錯誤用繁體中文。
4. 空清單的總分鐘是 0。
5. 只用 Python 標準函式庫；不要網路、API、金鑰或外部套件。
6. 可用 python worklog.py 執行，不依賴 Notebook 的變數。
7. 提供 total_minutes(minutes) 與 main()，使用 if __name__ == "__main__":。
8. 程式檔內不要包含 %%writefile、%run、!pip 或 Markdown 外框。
驗收：45 + 30 = 75 分鐘，也就是 1 小時 15 分鐘。
請另外說明：哪一行可修改活動資料、各函式做什麼，以及如何測試。

提示詞為什麼這樣寫？ 每一條都是為了讓結果可以驗收：

需求 目的
第 1、2 條：指定活動和輸出內容 結果固定，才能跟手算的答案對照
第 3 條：拒絕文字、小數、負數、布林值 工時只收整數分鐘；「-1 分鐘」這類不合理的資料要擋下來
第 4 條：空清單是 0 先講清楚特殊情況，AI 才不會自己猜
第 5 條：只用標準函式庫 標準函式庫是 Python 內建的工具，不用另外安裝，換到誰的電腦都能跑
第 6 到 8 條：能用 python worklog.py 執行 確保它是能單獨執行的正式程式檔，不是只能在 Notebook 裡跑的片段
驗收與說明 要 AI 交代清楚，你才知道要改哪裡、怎麼檢查

注意：每個人的 AI 給的程式都會不太一樣。為了讓全班走同一套流程，下一步先用老師準備的固定版本。你自己 AI 給的版本，可以課後拿來比較：它能不能通過第 05 步的 8 組檢查？

04｜把程式存成 worklog.py 檔

這一步在做什麼：把下方 Code 格裡的程式，存成一個獨立的檔案 worklog.py。

為什麼要做這一步？ 寫在 Notebook 格子裡的程式，只活在這份 Notebook 裡。把它存成 .py 檔，就像把草稿謄成正式文件：可以單獨交出去，也可以單獨執行。

怎麼做：在下方 Code 格按 Shift + Enter。

  • 第一行 %%writefile worklog.py 是 Jupyter 的存檔指令，意思是「把這一格的內容寫進 worklog.py」。這一行本身不會被寫進檔案。
  • 這一步只存檔，不會計算，所以還看不到 75 分鐘。就像書狀存檔了，不等於已經遞狀。

做對了會看到：Writing worklog.py（第一次建立）或 Overwriting worklog.py（覆蓋舊檔）。

注意：每執行一次，就會覆蓋同名的舊檔。想保留舊版，請先另存一份。

Notebook · Code 格 · Shift + Enter
%%writefile worklog.py
"""案件工時紀錄器：虛構教學資料，單位為整數分鐘。"""


def total_minutes(minutes):
    """加總非負整數分鐘；空清單回傳 0。"""
    total = 0
    for value in minutes:  # 一筆一筆檢查
        # True／False 在 Python 裡會被當成 1／0，所以要另外擋下來
        if isinstance(value, bool) or not isinstance(value, int):
            raise TypeError("分鐘必須是整數，不能是文字或小數。")
        if value < 0:
            raise ValueError("分鐘不能是負數。")
        total += value  # 通過檢查，才加進總數
    return total


def main():
    # 學生可修改這一行的活動名稱及分鐘。
    records = [("會議", 45), ("整理資料", 30)]
    # 只取出每筆的分鐘數，交給 total_minutes 加總
    total = total_minutes([minutes for activity, minutes in records])
    for activity, minutes in records:
        print(f"{activity}：{minutes} 分鐘")
    hours, remaining = divmod(total, 60)  # 換算成幾小時又幾分鐘
    print(f"總計：{total} 分鐘（{hours} 小時 {remaining} 分鐘）")


# 直接執行這個檔案時（python worklog.py），才啟動 main()
if __name__ == "__main__":
    main()

讀懂這段程式（不用背，看得懂意思就好）

程式 白話意思
def total_minutes(minutes): 做一個「加總工時」的小工具：交給它一串分鐘數，它算出總和
for value in minutes: 一筆一筆檢查
isinstance(...) 那一行 不是整數就退件（文字、小數都不行）
if value < 0: 負數也退件
raise TypeError(...)、raise ValueError(...) 退件，並顯示括號裡的錯誤原因
total += value 檢查通過，加進總數
def main(): 主程式：這個工具實際要做的事
records = [("會議", 45), ("整理資料", 30)] 活動資料，每筆是「（名稱, 分鐘）」。這是唯一需要修改的地方
divmod(total, 60) 總分鐘除以 60，得到「幾小時」和「剩幾分鐘」
print(...) 把結果顯示出來
if __name__ == "__main__": 「直接執行這個檔案時，就啟動 main()」。先當成固定寫法即可

為什麼連 True／False 也要擋？ 在 Python 裡，True 會被當成 1、False 會被當成 0。如果不擋，有人誤填 True，程式會默默算成 1 分鐘，也不會報錯。這種「看起來正常、其實算錯」的情況最危險，所以要明確拒絕。

import sys
from pathlib import Path

script = Path("worklog.py").resolve()
if not script.is_file():
    print("請先執行第 04 步存檔的那一格。")
else:
    result = subprocess.run(
        [sys.executable, "-X", "utf8", str(script)],
        capture_output=True, text=True, encoding="utf-8", timeout=10
    )
    print(result.stdout, end="")
    if result.stderr:
        print(result.stderr)
    print("結束代碼：", result.returncode, "（0 代表成功）")
    if result.returncode != 0:
        raise RuntimeError("執行失敗，請保留錯誤訊息。")

老師示範②：用 8 組已知答案檢查

這一步在做什麼：自動測試 8 組資料，其中 4 組應該算出正確答案，4 組不合理的資料應該被拒絕。學生看結果就好。

為什麼要做這一步？ 只試一組資料，可能剛好碰對。審查契約不會只看一條，測試也要涵蓋一般情況、特殊情況，以及不合理的輸入。好的工具不只要算對，還要擋住錯的資料。

測試資料 預期結果 為什麼測這組
45、30 75 跟手算答案對照
空清單（沒有任何活動） 0 特殊情況：什麼都沒填
0 0 特殊情況：0 分鐘是合法的
45、30、20 95 多一筆也要算對
-1 拒絕 工時不可能是負數
文字 "30" 拒絕 文字不是數字，不能相加
1.5 拒絕 本工具只收整數分鐘
True 拒絕 避免被默默當成 1 分鐘

做對了會看到：通過 8 組檢查：4 組正確資料，以及 4 組不合法輸入。 有任何一組沒通過，會出現錯誤訊息並停下來。

# 老師示範：用 8 組已知答案測試 worklog.py 裡的 total_minutes（學生看結果即可）
import importlib.util
from pathlib import Path

script = Path("worklog.py").resolve()
if not script.is_file():
    print("請先執行第 04 步存檔的那一格。")
else:
    spec = importlib.util.spec_from_file_location("lesson_worklog", script)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    for values, expected in [([45, 30], 75), ([], 0), ([0], 0), ([45, 30, 20], 95)]:
        assert module.total_minutes(values) == expected
    for values, error in [([-1], ValueError), (["30"], TypeError), ([1.5], TypeError), ([True], TypeError)]:
        try:
            module.total_minutes(values)
        except error:
            pass
        else:
            raise AssertionError(f"這組資料應該被拒絕：{values!r}")
    print("通過 8 組檢查：4 組正確資料，以及 4 組不合法輸入。")

修改一次，確認執行的是新檔案

為什麼要做這一步？ 要確定你改到的是真正的檔案，不是看到舊結果。資料改了，答案就該跟著變；沒變，就代表某個環節沒做到。

步驟 1：回到 Notebook 第 04 步的 Code 格，找到 records 那一行，整行改成下面這樣（前面的 4 個空格要保留）：

    records = [("會議", 45), ("整理資料", 30), ("準備簡報", 20)]

步驟 2：在那一格按 Shift + Enter，把新內容存進檔案。

步驟 3：回到第二個 Prompt，再執行一次 python worklog.py。

先手算：45＋30＋20＝95 分鐘（1 小時 35 分鐘）。畫面上的總計跟你算的一樣，就完成了。

注意：還是 75？ 最常見的原因是改了格子，卻沒有按 Shift + Enter 重新存檔：格子裡的字改了，硬碟上的檔案還是舊的。另外，新的 records 要取代原本那一行，不要加在程式最下面。

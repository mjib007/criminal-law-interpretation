01｜建立 Python 與 Jupyter 環境

這格在做什麼：準備本機工作空間。以下指令在 Windows 的 Anaconda Prompt 執行，不要貼到 Notebook。

  1. 從 Anaconda 官方下載 選適合電腦架構的 Windows 安裝程式。選個人使用 Just Me；保留不加入 PATH 的預設選項。
  2. 已有 Anaconda 或 Miniconda：在開始選單開啟 Anaconda Prompt，輸入 conda --version，能顯示版本即可沿用，不重複安裝。
  3. 在 Anaconda Prompt 逐行貼上以下兩行。詢問是否繼續安裝時，讀取畫面後輸入 y；若有服務條款提示，依學校及個人適用條件處理。
conda create -n law-vibe python=3.12 notebook ipykernel
conda activate law-vibe

第一行建立課程環境，第二行切換進去。成功時提示列前方應顯示 (law-vibe)。Python 3.12 是本課統一版本，不是宣稱最新版。

建立資料夾並啟動

繼續在同一個 Anaconda Prompt 逐行貼上。%USERPROFILE% 代表你自己的 Windows 使用者資料夾。

if not exist "%USERPROFILE%\law_vibe" mkdir "%USERPROFILE%\law_vibe"

瀏覽器開出 Jupyter 即成功；若沒自動開啟，把 Prompt 顯示的完整本機網址貼進瀏覽器。啟動它的 Prompt 視窗先留著，本機登入網址不要公開。

這些是 Anaconda Prompt（cmd） 指令，不能直接貼進 PowerShell、Notebook 或 Python 的 >>>。安裝下載請課前完成，時間依設備與網路而異；Mac 同學需另用對應指令。

03｜先定答案，再請 AI 幫忙

這格在做什麼：把需求交給 AI。先手算：會議 45 分鐘＋整理資料 30 分鐘＝75 分鐘，也就是 1 小時 15 分鐘。

把以下提示詞貼到你使用的 AI 對話。這段是需求，不是要貼進 Code 格的 Python。

我要做一個給法律系學生練習的「案件工時紀錄器」。
請先用白話重述需求，再提供完整的 worklog.py 程式。
需求：
1. 使用虛構活動：會議 45 分鐘、整理資料 30 分鐘。
2. 印出每項活動，最後印出總分鐘與幾小時幾分鐘。
3. 分鐘只能是非負整數；文字、小數、負數與布林值都要拒絕，錯誤用繁體中文。
4. 空清單的總分鐘是 0。
5. 只用 Python 標準函式庫；不要網路、API、金鑰或外部套件。
6. 可用 python worklog.py 執行，不依賴 Notebook 的變數。
7. 提供 total_minutes(minutes) 與 main()，使用 if __name__ == "__main__":。
8. 程式檔內不要包含 %%writefile、%run、!pip 或 Markdown 外框。
驗收：45 + 30 = 75 分鐘，也就是 1 小時 15 分鐘。
請另外說明：哪一行可修改活動資料、各函式做什麼，以及如何測試。

你的工作是定需求、提供已知答案、驗收結果。AI 的工作是提供程式與解釋。先請它指出可修改資料的位置，再用測試確認，不能只相信「已完成」。以下提供固定範例，讓全班先走通流程。

04｜產生 worklog.py

這格在做什麼：把以下完整內容寫成檔案。這一步只存檔，不會計算工時。

操作位置：Notebook 的新 Code 格。%%writefile worklog.py 必須在第一行，它是 IPython 指令，不會被寫進產生的 .py。

預期看到 Writing worklog.py 或 Overwriting worklog.py。

再執行會覆寫目前資料夾的同名檔，要保留舊版請先另存。AI 答案外側的三個反引號不要貼進 Code 格。本課後續格子只依賴磁碟上的 worklog.py，不依賴前一格的 Python 變數；沒檔案時會提示先產生。

Notebook · Code 格 · Shift + Enter
%%writefile worklog.py
"""案件工時紀錄器：虛構教學資料，單位為整數分鐘。"""


def total_minutes(minutes):
    """加總非負整數分鐘；空清單回傳 0。"""
    total = 0
    for value in minutes:
        if isinstance(value, bool) or not isinstance(value, int):
            raise TypeError("分鐘必須是整數，不能是文字或小數。")
        if value < 0:
            raise ValueError("分鐘不能是負數。")
        total += value
    return total


def main():
    # 學生可修改這一行的活動名稱及分鐘。
    records = [("會議", 45), ("整理資料", 30)]
    total = total_minutes([minutes for activity, minutes in records])
    for activity, minutes in records:
        print(f"{activity}：{minutes} 分鐘")
    hours, remaining = divmod(total, 60)
    print(f"總計：{total} 分鐘（{hours} 小時 {remaining} 分鐘）")


if __name__ == "__main__":
    main()

教師驗證：讓另一個 Python 執行

這格在做什麼：用相同 Python 開啟新行程，確認不依賴 Notebook 記住的變數。預期同樣出現 75 分鐘，結束代碼 0。這段輔助碼不用學生背誦。

Notebook · Code 格 · Shift + Enter
import subprocess
import sys
from pathlib import Path

script = Path("worklog.py").resolve()
if not script.is_file():
    print("請先執行『產生檔案』那一格。")
else:
    result = subprocess.run(
        [sys.executable, "-X", "utf8", str(script)],
        capture_output=True, text=True, encoding="utf-8", timeout=10
    )
    print(result.stdout, end="")
    if result.stderr:
        print(result.stderr)
    print("結束代碼：", result.returncode, "（0 代表成功）")
    if result.returncode != 0:
        raise RuntimeError("執行失敗，請保留錯誤訊息。")

驗證正確與錯誤輸入

這格在做什麼：自行載入 .py 裡的函式，檢查 8 組已知答案。預期看到「通過 8 組檢查」。這格不需要先跑其他格子的 import 或函式定義，只需已存在 worklog.py。

測試資料 預期
45、30 75
空清單 0
0 0
45、30、20 95
-1 拒絕負數
文字 "30" 拒絕文字
1.5 拒絕小數
True 拒絕布林值
Notebook · Code 格 · Shift + Enter
import importlib.util
from pathlib import Path

script = Path("worklog.py").resolve()
if not script.is_file():
    print("請先執行『產生檔案』那一格。")
else:
    spec = importlib.util.spec_from_file_location("lesson_worklog", script)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    for values, expected in [([45, 30], 75), ([], 0), ([0], 0), ([45, 30, 20], 95)]:
        assert module.total_minutes(values) == expected
    for values, error in [([-1], ValueError), (["30"], TypeError), ([1.5], TypeError), ([True], TypeError)]:
        try:
            module.total_minutes(values)
        except error:
            pass
        else:
            raise AssertionError(f"這組資料應該被拒絕：{values!r}")
    print("通過 8 組檢查：4 組正確資料，以及 4 組不合法輸入。")

修改一次，確認不是舊結果

回到第 04 步產生檔案的 Code 格，將原本 records 那一行改成：

    records = [("會議", 45), ("整理資料", 30), ("準備簡報", 20)]

保留原本的縮排，重跑存檔格，再到 Prompt 執行 python worklog.py。手算結果應是 95 分鐘（1 小時 35 分鐘）。

只修改格子，卻沒執行存檔格，磁碟上的檔案仍是舊版。不要將新 records 加到程式最下方，要修改 main() 裡原有那一行。
